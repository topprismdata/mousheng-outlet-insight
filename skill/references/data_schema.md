## 3. 三类查询对应的字段入口

- **A 明确条件**：`规划大区` `省份` `城市` `区县` `渠道组` `子渠道` `细分渠道` `连锁品牌名称` `是否连锁` `携程-房间数` `携程-星级` `LINX MT黄金门店` `经营场所` `经营场所名称`
- **B 分布探索**：`group_by` 常用 `渠道组` / `子渠道` / `细分渠道` / `经营场所` / `经营场所名称` / `规划大区` / `城市`；`metrics` 用 `count`（数值字段可 `avg`/`sum`）
- **C 规则排行**：候选维度默认 `经营场所名称`；规则常用 `count`、`_derived:开店年限`、`大众点评餐饮点评评分星级`、`周末均值客流(人)`

## 4. 字段语义映射

口语别名 → 真实字段的映射表见 `references/field_registry.json`（解析器加载它）。
新增可识别的口语词，直接在该 JSON 的 `alias` / `synonyms` 里加即可，无需改代码。

## 5. 统计画像层（profiler）

- 字段真实统计由 `scripts/profiler.py` 计算并缓存到数据同级的 `<数据>.profile.json`。
- 模糊度量词（评分/客流/潜力/房间数…）由 `route_metric` 按业态覆盖率路由到正确字段。
- 查看：`agent_cli.py --profile [字段]`；外部 Agent 经 MCP `profile` tool 按需查询。
