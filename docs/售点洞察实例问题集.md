> 数据基础：`<data>` <n_rows> 行 × 152/<n_cols> 列（潜客画像数据，全库 `服务状态=未服务`）。

## A 组：能力对比 10 题（复杂、充分体现 Skill 能力）

来源：为回答"自己设计 10 个复杂问题并与直接问大模型对比"而实跑验证。全部在真实数据上跑通，34→36 项回归中包含对应用例。

| # | 问题原文 | 考察能力 | 实测要点 |
|---|---|---|---|
| A1 | 目标子区域B未服务的美宜佳，按月均收入潜力预测从高到低取前10 | 私有实体 + 口径消歧 | "美宜佳"→`连锁品牌名称 contains '美宜佳'`；"潜力"在 3 个候选列中选 `月均收入潜力预测(无协议无冰柜)`；链式 346→37 行子集。`服务状态=未服务` 全库恒真（合法无操作） |
| A2 | 住宿客户按评分从高到低排序取前10 | 评分路由·住宿 | `route_metric("评分",业态=住宿)`→`携程-综合评分`（修复前误路由到餐饮点评列） |
| A3 | 餐饮客户按评分从高到低排序取前10 | 评分路由·餐饮 | `route_metric("评分",业态=餐饮)`→`大众点评餐饮点评评分星级` |

| A5 | 商场里餐饮客户不低于20家为达标，周末客流从高到低排序，点评评分3.8分以上占比50%以上为高，开业3年以上占比50%以上为高，取前10 | C 类规则排行 + 体检 | 3 条规则 + 等级判定 + 输出 CSV 含「数据完整度%」列 + 派单建议；自动跳过食杂不适用的点评/房间维度 |

## B 组：火锅店 & 时间谓词查询（用户真实需求 + 口语变体）

来源：用户提出"查餐饮街营业到晚10点以后的火锅店"，我们落地了语义层**时间谓词**（close_after / open_after 算子），并用一组口语验证解析器。

| # | 问题原文 | 性质 | 解析 / 实测要点 |
|---|---|---|---|
| B11 | 帮我查询所有营业到晚上10点以后在餐饮街的火锅店 | `[用户]` 原话 | 三层过滤：火锅类子渠道(27,503) ∩ 餐饮街(6,281) ∩ 闭店>22:00(2,051)；正常营业 1,891 |
| B12 | 餐饮街营业到晚10点以后的门店 | `[设计]` | 时间谓词经 DSL 原生生效：`{大众点评营业时间, close_after, 22}`；真实跑出 17,711 家（餐饮街 101,986 ∩ 晚10点后 79,811） |
| B13 | 餐饮街营业到晚上10点以后的火锅店 | `[设计]` | 在上条基础上自动叠加 `连锁品牌名称 contains '火锅'`，得 269 家（"火锅"被解析为品牌名包含，非打包子渠道） |
| B14 | 晚10点后 | `[测试]` 口语 | `parse_time_predicate` → `close_after 22.0`（晚上+12 转 24 小时制） |
| B15 | 10点以后营业 | `[测试]` | → `close_after 10.0`（无"晚/夜"修饰，按 24 小时制 10:00 后） |
| B16 | 营业到晚上8点以后 | `[测试]` | → `close_after 20.0` |
| B17 | 凌晨2点后还开的 | `[测试]` | → `open_after 2.0`（指开店时刻晚于凌晨 2 点，即夜宵/通宵类） |
| B18 | 22点以后才开门的夜宵店 | `[测试]` | → `open_after 22.0` |
| B19 | 24小时营业的 | `[测试]` | 识别"24小时/全天"→ 闭店 24:00 视作 >22:00，命中 `close_after` |
| B20 | 通宵营业 | `[测试]` | 识别"通宵/过半夜"→ 闭店小时 < 开店小时段，命中 `close_after` |

**补充负样本（不计入 20，仅作护栏验证）：**
- `[反例]` 营业3年以上的餐饮店 → 验证"X年以上"不被误判为时间谓词（归属开业年限字段，非营业时间文本）。
- `[反例]` 闭店正好 `22:00` 整（如 `周一至周日 10:00-22:00`）→ 明确**不计入**"晚10点以后"（严格 >22:00），共 555 家边界样本单列。

## 备注

1. **"火锅"口径差异**：数据无纯"火锅"子渠道，`细分渠道` 为打包值 `中档餐馆-火锅烧烤小龙虾川湘菜`。B11 用打包子渠道得 2,051 家；B13 用品牌名包含"火锅"得 269 家（更贴纯火锅，但漏无品牌店）。如需后者，可把"火锅"注册为 `domain_entities` 映射到 `细分渠道`。
2. **时间谓词已沉淀为语义层一等公民**：`scripts/bizhours.py` + `nl_parser`/`agent_core`/`engine` 三处接线，受 `validate_query` 护栏放行，DataFusion 路径自动回退 pandas；回归测试 T36 覆盖 6 种口语 + 引擎回退 + 反例。
3. **A 组 A7/A9/A10 为测试 DSL 或引擎对照**，并非自然问句；列出是为完整反映"验证用实例"。
