# 谋圣·售点洞察 Agentic 地图 Demo

这是一个由真实查询链路驱动的 Agentic 地图演示。它通过本地适配服务复用现有自然语言解析、查询引擎与 `Insight Component`，不是传统 BI 看板，也不是写死结果的静态原型。

## 启动

在项目根目录执行：

```bash
.venv/bin/python demo/server.py
```

然后访问 `http://127.0.0.1:8765`。首次启动需要将 629,074 行真实数据载入内存，通常需等待几十秒；后续查询直接复用会话工作集。

## 建议演示顺序

1. 等待右上角显示“真实数据已连接”。
2. 点击上海区县地图，让 Agent 将行政区上下文转成真实清单。
3. 选择底部真实基准问题，观察 Agent 的理解、编译、查询、质量校准与洞察步骤。
4. 在输入框改写问题，继续进行自然语言探索。
5. 点击 Agent 推荐的下一问，体验连续分析，而不是固定筛选器。
6. 打开清单与 `InsightPackage`，核对地图表达背后的真实数据、限制和溯源。

## 演示边界

- 查询结果来自项目现有 629,074 行真实售点数据及真实语义查询链路。
- 底部推荐问题来自现有 52 组基准查询，不是为界面临时编造。
- 地图只表达真实区县聚合；由于没有经纬度，不展示或伪造精确点位、距离和热力。
- 本地服务是外围演示适配层，不改变 Insight Component 只消费三元契约、只输出洞察包的独立边界。
- Agent 不包含派单、排程、路线或 CRM 写入能力。

## 正式集成

正式产品应把当前本地 HTTP 适配层替换为 Gateway/Engine 服务；地图和 Agent UI 继续消费结构化查询结果与 `InsightPackage`。
